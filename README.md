# Документация - Утилита измерения задержки (Latency Test)

## Обзор

Этот проект содержит две реализации утилиты для измерения задержки (latency) HTTP-запросов к заданному URL. Обе версии выполняют одну и ту же функцию, но написаны на разных языках программирования:

- **test_ping.go** - реализация на языке Go
- **test_ping.py** - реализация на языке Python

Обе программы эмулируют современные браузеры (Chrome) для обхода защиты от ботов и предоставляют детальную статистику о времени отклика сервера.

---

## 📋 Возможности

- ✅ Эмуляция браузера Chrome для обхода антибот-защиты
- ✅ Прогревочный запрос (warm-up) для исключения холодного старта
- ✅ Множественные тесты с настраиваемой задержкой между запросами
- ✅ Детальная статистика:
  - Средняя задержка (Average latency)
  - Минимальная задержка (Min latency)
  - Максимальная задержка (Max latency)
  - 95-й перцентиль (95th percentile)
  - 99-й перцентиль (99th percentile)

## 🔧 Установка и требования

### Версия на Go (test_ping.go)

**Требования:**
- Go версии 1.16 или выше

**Установка зависимостей:**
```bash
go mod tidy
```

**Сборка:**
```bash
go build -o ping_test.exe test_ping.go
```

**Использование готового бинарника для Linux:**

В проекте доступен готовый скомпилированный бинарник для Linux (AMD64): `ping_test_linux`

```bash
# 1. Сделайте файл исполняемым
chmod +x ping_test_linux

# 2. Запустите
./ping_test_linux -url "https://example.com" -num_tests 5 -delay 1.0
```

> **Примечание:** Бинарник статически скомпилирован и не требует установки Go или каких-либо зависимостей на Linux системе.

### Версия на Python (test_ping.py)

**Требования:**
- Python 3.7 или выше

**Установка зависимостей:**
```bash
pip install curl_cffi
```

## 🚀 Использование

### Версия на Go

**Запуск скомпилированной программы:**
```bash
./ping_test.exe -url "https://example.com" -num_tests 5 -delay 1.0
```

**Запуск через go run:**
```bash
go run test_ping.go -url "https://example.com" -num_tests 5 -delay 1.0
```

**Параметры командной строки:**

| Параметр | Тип | Обязательный | Значение по умолчанию | Описание |
|----------|-----|--------------|----------------------|----------|
| `-url` | string | ✅ Да | - | URL для тестирования (с параметрами если нужно) |
| `-num_tests` | int | ❌ Нет | 5 | Количество тестов для выполнения (после прогрева) |
| `-delay` | float64 | ❌ Нет | 1.0 | Задержка в секундах между запросами |

**Примеры использования:**

```bash
# Базовое использование - 5 тестов с задержкой 1 секунда
./ping_test.exe -url "https://api.example.com/endpoint"

# 10 тестов с задержкой 2 секунды
./ping_test.exe -url "https://api.example.com/endpoint" -num_tests 10 -delay 2.0

# URL с параметрами
./ping_test.exe -url "https://api.example.com/search?q=test&limit=100"

# Быстрое тестирование - 3 теста с минимальной задержкой
./ping_test.exe -url "https://example.com" -num_tests 3 -delay 0.5
```

### Версия на Python

**Запуск:**
```bash
python test_ping.py "https://example.com" --num_tests 5 --delay 1.0
```

**Параметры командной строки:**

| Параметр | Тип | Обязательный | Значение по умолчанию | Описание |
|----------|-----|--------------|----------------------|----------|
| `url` | string | ✅ Да | - | URL для тестирования (с параметрами если нужно) |
| `--num_tests` | int | ❌ Нет | 5 | Количество тестов для выполнения (после прогрева) |
| `--delay` | float | ❌ Нет | 1.0 | Задержка в секундах между запросами |

**Примеры использования:**

```bash
# Базовое использование - 5 тестов с задержкой 1 секунда
python test_ping.py "https://api.example.com/endpoint"

# 10 тестов с задержкой 2 секунды
python test_ping.py "https://api.example.com/endpoint" --num_tests 10 --delay 2.0

# URL с параметрами
python test_ping.py "https://api.example.com/search?q=test&limit=100"

# Быстрое тестирование - 3 теста с минимальной задержкой
python test_ping.py "https://example.com" --num_tests 3 --delay 0.5
```

## 🔍 Технические детали

### Архитектура программы

Обе версии программы следуют одинаковой логике:

1. **Инициализация клиента** - создание HTTP-клиента с эмуляцией браузера Chrome
2. **Прогревочный запрос** - выполняется один запрос, результат которого игнорируется (для установки соединения, DNS-резолва и т.д.)
3. **Тестовые запросы** - выполняется заданное количество запросов с измерением времени
4. **Вычисление статистики** - расчет среднего, минимума, максимума и перцентилей
5. **Вывод результатов** - отображение всех метрик в миллисекундах

### Используемые библиотеки

**Go версия:**
- `github.com/enetx/g` - утилиты для работы со строками
- `github.com/enetx/surf` - HTTP-клиент с поддержкой эмуляции браузера

**Python версия:**
- `curl_cffi` - обертка для curl с поддержкой эмуляции браузера и обхода защиты

### Метрики

**Average Latency (Средняя задержка)** - среднее арифметическое всех измерений. Показывает общую производительность.

**Min/Max Latency (Минимальная/Максимальная задержка)** - экстремальные значения. Помогают понять разброс.

**95th Percentile (95-й перцентиль)** - 95% запросов выполняются быстрее этого времени. Показывает типичную производительность, отсекая выбросы.

**99th Percentile (99-й перцентиль)** - 99% запросов выполняются быстрее этого времени. Помогает оценить worst-case сценарии.

## 🛠️ Устранение неполадок

### Ошибка: "undefined: g" (Go версия)

**Решение:**
```bash
go mod tidy
go build
```

### Ошибка: "ModuleNotFoundError: No module named 'curl_cffi'" (Python версия)

**Решение:**
```bash
pip install curl_cffi
```

### URL с параметрами не работает

**Решение:** Заключите URL в кавычки:
```bash
# Правильно
./ping_test.exe -url "https://api.example.com/search?q=test&limit=100"

# Неправильно
./ping_test.exe -url https://api.example.com/search?q=test&limit=100
```

### Запросы блокируются сервером

Обе версии эмулируют реальный браузер Chrome, но некоторые сайты могут все равно блокировать запросы. В этом случае:
- Увеличьте задержку между запросами (параметр `--delay`)
- Уменьшите количество тестов (параметр `--num_tests`)
- Проверьте, не требует ли сайт дополнительную аутентификацию
